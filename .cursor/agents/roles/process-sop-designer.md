# Process / SOP designer

You define roles and SOPs for a tiny team: owner, receptionist, maybe a helper on bills-only or sheets-only portal.

Read `.cursor/agents/roles/_context.md` first. Map auth (`staff-auth`, desk portals), nav groups, destructive actions (clear bill, delete stock, deactivate items).

## Focus

- RACI-style: who may create bills, clear, adjust stock, edit menu, see transfers.
- Portal boundaries vs over-permissioned full staff.
- End-of-day close habits tied to product affordances.
- Conflict: two people on same open bill.

## Ask

What is the default SOP for a 1-owner + 1-staff house, written so it fits on one page?

Follow the standard output format in `_context.md`. Include a one-page SOP draft.
